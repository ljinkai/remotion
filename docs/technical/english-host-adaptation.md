# 英文数字人分镜适配

对应规范：`openspec/changes/adapt-english-host-scenes/`。

## 使用

在 Workbench 选择 EN，载入英文内容，再按现有顺序生成逐字稿、分镜、语音和 MP4。默认英文音色沿用已有配置，人物素材不需要重做。没有真实分镜时，英文人物示例仅用于预览，不允许当作当前内容导出。

## 实现边界

- `locale: en` 贯穿工作台属性、分镜增强、预览和数字人组件。
- 英文连接词用于识别流程、并列功能与明确对比；保留否定词、限定词和 `or` 的选择含义。
- 不同单位指标按独立事实展示，已有核对图表和原图仍优先。不得把金额范围、收入增长或两个备选工具仅凭 `from/to/or` 画成操作流程。
- 数字人内置章节、图像状态、关系图和图表说明使用英文；原图像素与作者提供的来源文字保留原语言，不静默翻译。
- 英文长标题与解释文字使用可读换行、必要时按原时长分页；品牌和完整数字不得在中间截断。
- 人物始终保持固定大尺寸和右下位置，黄色字幕的高度与显示层级不变。

## 验证范围

测试覆盖英文与中文识别、否定与备选关系、不同单位指标、旧缓存幂等、locale 透传、英文样例导出限制，以及英文标题和字幕。实际渲染覆盖流程、功能、对比、指标、长标题、原图和缺图状态。

本轮通过静音渲染验证视觉和时间轴，不会额外调用收费 LLM 或 TTS，也不宣称验证了英文音素级口型或语音精确同步。最终测试和输出记录见对应 `tasks.md`。
