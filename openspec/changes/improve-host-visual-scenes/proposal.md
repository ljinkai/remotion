# Change: 优化数字人分镜的中间内容表现

## Why

当前内容区主要是等分网格、拉伸卡片和重复文字，难以表达产品、数据和步骤。用户已确认采用按内容选择镜头的方案，并明确要求展示当前内容引入的图片。本变更记录该授权范围。

## What Changes

- 增加产品实景、核心数字、步骤流程、观点强调四种中间区域构图，动画按建立画面、揭示重点、停留的节奏计算。
- 分镜可带可选 `scene` 类型，保留原逐字稿行、顺序、时间轴及既有元素结构。
- 每个有图片的案例在其分镜中展示自身原图；已提供的有效图片不得因布局选择或元素限额而遗漏。
- 产品图使用完整展示优先的排版和轻微推进；其他镜头仍可带辅助图片，图片加载失败有可读回退。
- 已缓存的分镜也应用保守的场景和图片补全，预览与导出共用结果。
- 不生成原文不存在的数字、增长曲线、产品功能或步骤，不扩大到语音唇形、主持人重绘或逐镜编辑器。

## Impact

- Affected specs: `script-driven-beats`。
- Affected code: `ElementStage`、`HostFromBeats`、分镜类型、生成提示词、校验与 Workbench 分镜整理逻辑。
- 旧分镜没有 `scene` 时保留兼容，其他周刊模板及主持人布局不变。
