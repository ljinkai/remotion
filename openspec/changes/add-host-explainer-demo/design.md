# Design: 主持人讲解实验合成

## Context

现有竖屏合成把案例截图做成大图，字幕贴在下方。这次实验是另一套版式：浅色网点纸、顶部章节和进度、一句大标题、中间一组扁平插画、左下角持续存在的清单、右下角同一个主持人。

实验合成使用写死的三镜脚本。预览入口是 Remotion Studio。审核通过之前不写实现代码。

## Goals / Non-Goals

- Goals:
  - 一条 15 秒、可在 Studio 里逐帧查看的 1080×1920 合成
  - 三镜中间图形不同，外壳（网点、章节、进度、清单、主持人）持续存在
  - 主持人有两种身体姿势，说话时嘴型循环
  - 清单高亮与当前镜一致
  - 全部图形可从本文档直接画出来，不依赖外链图片
- Non-Goals:
  - 接入 Markdown、千问、Azure、Workbench 或 `/api/v1/render-jobs`
  - 口型对齐到音素；本实验没有语音
  - 复刻参考视频的文案、配色商标或人物肖像
  - 修改现有周刊合成的布局
  - 引入新的字体文件。强调词用 Inter 斜体加橙色

## Decisions

### 1. 合成身份

| 项 | 值 |
|----|----|
| Composition id | `HostExplainerDemo` |
| 尺寸 | 1080×1920 |
| fps | 30 |
| 时长 | 450 帧（15.0 秒） |
| 注册位置 | `src/Root.tsx`，与现有两个周刊合成并列 |
| 数据 | `src/host-explainer/demoScript.ts` 内的常量，无 props 输入 |

三镜各占 150 帧，Sequence 起点为 0、150、300。镜与镜之间不做交叉溶解：当前镜在第 138–149 帧淡出（opacity 1→0），下一镜从第 0 帧淡入（0–12 帧 opacity 0→1）。外壳不淡出。

### 2. 色彩与字体

| Token | 值 | 用途 |
|-------|----|------|
| paper | `#f4f1ea` | 底色 |
| dot | `rgba(28,28,28,0.16)` | 网点 |
| ink | `#161616` | 正文、描边 |
| muted | `#8a8178` | 章节、次要字 |
| accent | `#ff4d1c` | 强调词、进度数字、柱子、高亮 |
| card | `#fffcf8` | 清单和插画卡片 |
| line | `#e4ddd4` | 卡片内未选中底 |

字体沿用项目已有的 Inter / 苹方。标题约 68px、字重 760、行高 1.05。强调词 `font-style: italic`，颜色 `accent`。章节 22px，字距 0.04em，颜色 `muted`。

网点：在 paper 上铺一层径向圆点，直径 2px，间距 18px，颜色 `dot`。用 CSS `radial-gradient` 即可，不另存图片。

### 3. 画面分区（1080×1920）

```
y 56–110     左：章节    右：进度
y 160–420    大标题，左右边距 64
y 460–1280   中间插画
y 1320–1560  左下清单（宽 640）
y 1280–1920  右下主持人（宽 460，贴右贴底）
y 1588–1660  字幕，水平居中，位于清单下沿附近
```

右侧 72px、底部 48px 留给画面内元素，不绘制平台的点赞或评论按钮。

### 4. 三镜脚本

清单三镜共用，标题为 `// 怎么读一条案例`。未选中项底色 `line`、字色 `ink`。选中项底色 `ink`、字色 `#fff`。右上角进度用 `accent` 显示 `1/3`、`2/3`、`3/3`。

| 镜 | 帧 | 章节 | 顶栏进度 | 标题（橙色为强调） | 清单选中 | 姿势 | 字幕 |
|----|----|------|----------|--------------------|----------|------|------|
| 1 产品页 | 0–149 | `// 01 – 产品页` | `信号 1/3` | 先看它的**产品**长什么样 | 01 产品页 | point | 先看产品页，知道它在卖什么。 |
| 2 收入 | 150–299 | `// 02 – 收入` | `信号 2/3` | 再看它一个月能到 **$12,000** | 02 收入 | cheer | 再看收入，这款一个月一万二。 |
| 3 打开看 | 300–449 | `// 03 – 打开看` | `信号 3/3` | 最后打开手机，功能就在**首屏** | 03 打开看 | point | 最后打开手机，功能就在首屏。 |

字幕在该镜第 12 帧出现，第 138 帧开始淡出。没有音频。嘴型仍按「正在说」的区间循环，用来看口型节奏，不表示真实语音。

### 5. 人物：阿周

原创扁平矢量，腰部以上，正面三分之二。不从参考图描摹，不放入任何参考截图。

结构（从下到上画）：外套 → 白 T 恤 → 脖子 → 头 → 耳朵 → 胡子 → 嘴 → 鼻 → 眼和眼镜 → 头发 → 毛线帽 → 手臂。手臂盖在外套之上。

尺寸与颜色（在 460×640 的人物画板内，原点在画板左上角）：

| 部件 | 画法 | 颜色 |
|------|------|------|
| 头 | 圆心 (230, 250)，半径 86 | 肤色 `#f3d2b5`，描边 ink 4px |
| 耳朵 | 头两侧各一个 18×28 椭圆 | 同肤色 |
| 头发 | 头上部的黑色块，刘海略偏画面左侧，盖住额头上沿 | `#161616` |
| 帽子 | 盖住头发上半的圆角矩形，高 70；帽前一条 22×10 的橙色标签 | 帽 `#161616`，标签 `#ff4d1c` |
| 眼镜 | 两个半径 24 的圆，镜框描边 5px，中间 10px 横梁 | 描边 `#161616`，镜片透明 |
| 眼 | 镜片内两个 6×8 的深色椭圆；闭眼时改成 2px 横线 | `#161616` |
| 鼻 | 短的 3px 弧 | `#161616` |
| 胡子 | 嘴以下的圆角块，左右连接到腮 | `#3a2a24` |
| 外套 | 宽 300、高 280 的梯形，圆角 36，领口敞开 | `#c4b5a4`，描边 ink 4px |
| T 恤 | 领口内的白色区域 | `#fffcf8` |

嘴在胡子上沿的缺口里，三种形状按帧切换，位置固定在头中心偏下（约 y=278）：

| 嘴型 | 形状 |
|------|------|
| closed | 宽 28、高 4 的圆角横条，颜色 `#161616` |
| mid | 宽 26、高 14 的椭圆，填充 `#161616` |
| open | 宽 30、高 22 的椭圆，填充 `#161616`，内部上沿一条 16×4 的 `#fff` 表示牙齿 |

姿势只换手臂，头和躯干不变：

| 姿势 | 左臂 | 右臂 |
|------|------|------|
| point | 自然下垂，贴在外套左侧 | 肘部弯曲，前臂指向左上方，食指伸出，其余手指收起。指尖大约落在清单右缘附近 |
| cheer | 肘部弯曲，拳头停在左颊旁 | 对称，拳头停在右颊旁 |

手的肤色与头相同，描边 4px。

动作：

- 身体上下浮动：`translateY(Math.sin(frame / 8) * 5)`，单位 px
- 闭眼：全局帧每 90 帧闭眼 3 帧（第 87–89、177–179、267–269、357–359）
- 张嘴：该镜本地帧在 12–137 时循环，每 5 帧一态，顺序 closed → mid → open → mid；其余时间 closed
- 换姿势发生在切镜的第一帧，不做手臂补间。实验先看两个关键姿势是否认得出

### 6. 中间插画

三组都是组件，不用图片文件。入场用 `spring({ damping: 14, stiffness: 120 })`。播放钮是共用组件：白色三角形，外接圆直径 88，阴影 `0 8px 0 rgba(22,22,22,0.08)`，缩放在 1 与 1.06 之间按 `Math.sin(frame / 6)` 循环。

**镜 1 · 产品页网格**

一张宽 920、圆角 32 的白卡片，顶栏左侧一个 72×72 的色块缩略图（橙底上三个深色矩形），旁边两行字：`产品墙` / `六款独立产品`。右侧一个胶囊 `翻看中…`，圆点用 accent。

下方 3 列 × 2 行小卡片，间距 16。每张小卡片高 168、圆角 18、描边 2px ink，内部是色块组成的假界面，底部写名称：

| 位置 | 名称 | 内部色块 |
|------|------|----------|
| 1 | 甲板笔记 | 顶部深色条，下面三条灰线 |
| 2 | 像素发票 | 左橙右灰的两栏 |
| 3 | 晨跑打卡 | 一个橙色圆加一条折线 |
| 4 | 书桌计时 | 三个等高的竖条，中间一条更高且为 accent |
| 5 | 海报工坊 | 大号浅灰矩形 |
| 6 | 订阅盒子 | 一个深色圆角方块 |

六张卡从第 4 帧起每张延迟 4 帧入场：自下方 24px 移到 0，透明度 0→1。播放钮叠在网格中心。

**镜 2 · 收入柱**

左侧一根圆角柱，宽 200、最大高 520、颜色 accent。柱顶一个黑底标签 `每月`，标签里是简化的山形折线。柱子高度从 0 长到 520，用该镜本地帧 0–28 的 spring。柱子下沿一条虚线，虚线右侧字 `$2,400`，再下面小字 `上月`。

柱子右侧大字 `$12,000`，72px，颜色 accent，字重 760。大字上方小字 `// 本月`，颜色 muted。播放钮在柱子和大字之间。右侧一个原创的收据图形：圆角矩形 120×160，顶上一条深色装订条，里面三条横线。不用法槌，避免和参考视频的法律题材绑在一起。

**镜 3 · 打开看**

左侧卡片宽 420、圆角 28，轻微逆时针 6 度。顶部橙色胶囊 `订阅制`。中间四根竖条波形，高度 36 / 64 / 88 / 52，颜色 accent 与 ink 交替。底部小字 `月付`。卡片从左侧 40px 处滑入。

右侧手机宽 340、高 620、圆角 44、外壳 `#161616`。屏幕 `#fffcf8`，顶部字 `本周上线`，下面一块白卡片写 `甲板笔记` 和一枚橙色按钮 `打开`。手机从右侧 40px 处滑入。播放钮夹在卡片和手机之间。

### 8. 预览

实现后执行 `npm run dev`，在 Remotion Studio 打开 `HostExplainerDemo`。逐镜看：标题强调色、清单选中项、中间图形入场、姿势在 point / cheer 之间切换、说话区间嘴型循环、闭眼。不要求渲染 MP4。

## Risks / Trade-offs

- 斜体 Inter 比参考图的手写强调字更朴素。实验先验证布局和节奏，换字体留到以后。
- 嘴型不跟真实语音。接上周刊旁白时再改成按字幕 cue 开关，那不是本实验的范围。
- 手臂不补间，切镜时姿势会跳。若审核时觉得跳，实现阶段可以加 8 帧插值，文档目前要求跳切。

## Migration Plan

无迁移。新合成是附加的。删除 `src/host-explainer/` 和 `Root.tsx` 里的注册即可撤掉实验。
