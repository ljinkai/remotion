# 证据驱动内容镜头

## 数据与来源

新增 chart 与 relationship 元素；原 image 元素允许归一化的 focus 区域。图表提供类型、标题、单位、标签、数值及可选原文显示形式和出处。单个数值不生成假的时间序列；占比需要明确整体；跨单位数据不能混在同一坐标轴。

`public/host-evidence.json` 记录人工核对原图的证据，包括图片路径、文件 SHA-256、图表、重点区域和关系节点。服务端读取原图并核对摘要，再向 Workbench 提供有效条目。生成和渲染接口使用服务端校验后的证据，不直接采信客户端上传的任意图表。

当前 GojiberryAI 配图含月经常性收入阶段；图表标明 USD/月、MRR，横轴为阶段而非日期。最后 `$150k+` 的数值只表示下界，不能显示为精确终点。年度 ARR 保留独立标签，不能与 MRR 绘成同一序列。该清单是明确的人工标注，不代表任意截图均可自动提取数据。

## 视觉结构

- 图表：按来源支持绘制阶段阶梯、对比或单值量级表达，不以装饰下划线代替图形。
- 图片：全图→重点区域→停留，放大时仍保留缩略出处；未标注图片使用明确标为局部的保守区域或全图回退。
- 关系：节点建立→突出当前渠道→聚焦单一路径；同案例相邻关系镜头共用整体进度，字幕行变化不导致重头播放。
- 信息主镜：紧凑章节导航、缩小右下主持人，保持字幕有独立可读区域。

## 兼容与验证

保留旧元素、无证据图片、原说话行、音轨和计时。旧缓存通过共享整理逻辑获得新视觉。证据缺失或图片已变化时，不使用旧标注；图片加载失败保留可读回退。

测试覆盖来源摘要匹配、非法图表/单位、下界显示、原图保留、相邻镜头连续、旧缓存与时间轴。实际 Workbench 导出并抽查阶段图、截图聚焦、策略关系及图片失败。抽查不等同全帧视觉检查，语音同步不在本轮范围。
