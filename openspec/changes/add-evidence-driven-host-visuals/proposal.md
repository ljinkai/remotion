# Change: 用来源证据驱动数字人图表、截图聚焦和关系镜头

## Why

当前分镜仍以文字和全图缩略为主，单值指标没有图表表达，相邻策略句缺少连续画面。用户已明确批准进一步优化图表、原图局部聚焦和渠道策略关系动画。

## What Changes

- 图表按实际数据结构绘制；当前 GojiberryAI 使用人工核对原图得到的 MRR 阶段数据，清楚区分 ARR、MRR、日期和阶段。
- 新增带图片 SHA-256 的来源证据清单与校验接口，只有匹配原图的条目才进入工作流；不把人工核对宣称为自动 OCR。
- 图片先全图建立出处，再展示重点区域，保留全图缩略图和说明。
- 策略句使用关系节点、聚焦和跨相邻字幕的连续进度，其他单值和无证据场景保留保守回退。
- 图表/截图主镜缩小主持人，案例导航压缩为章节条，为信息图留出空间。
- 沿用已有脚本、图片、音轨与缓存，预览和导出共用经校验的数据。

## Impact

- Affected specs: `script-driven-beats`。
- Affected code: 分镜元素与校验、证据加载、Workbench 客户端和接口、内容区和主持人布局。
- 本次不引入外部 OCR 服务，不改语音合成或其他周刊模板。
